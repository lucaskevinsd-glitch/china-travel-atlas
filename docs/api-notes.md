# API 选型备忘（核验于 2026-10-22，官方资料）

完整评估见第一阶段评估报告。本文件只记结论与待验证项，价格/额度以供应商控制台为准，变更后更新本文件日期。

## 天气

- **和风 QWeather（生产主选，未接入）**：实况、逐天 1–30 天、逐小时 24–168 小时、空气质量、生活指数（含旅游指数）。按量计费，每月前 50,000 次免费（天气与基础服务组），其后 0.0007 元/次起。必须注明来源；GeoAPI 禁止批量缓存/建索引（目的地坐标自备）。认证支持 JWT 与 API KEY，均只进 Worker Secret。待验证：天气缓存时长细则、注册认证流程、QPS、中国大陆坐标口径（上线前以 3 个已知地点实测）。
- **Open-Meteo（一期联调/兜底，已接）**：无密钥、按经纬度、7 天预报。免费档仅限非商业（600/分钟、5,000/小时、10,000/天），数据 CC BY 4.0 须标注来源；站点出现广告/收费即属商业用途，须改商用档。
- **高德天气（备选）**：`v3/weather/weatherInfo`，adcode 查询，Key 在 URL 参数中；预报仅 3 天，无逐小时与生活指数；实况每小时多次更新、预报每天约 8/11/18 点更新 3 次。官方配额定额未核到（文档页仅给跳转链接），待验证。
- **彩云天气（未选）**：官方价格页与旧价格单数字互相矛盾，无法做预算；Token 在 URL 路径中。待价格口径确认后再议。

## 密钥规则

任何带 Key/Token 的服务一律经 Cloudflare Worker 代理（Workers 免费版 100,000 请求/天）。前端代码与仓库中只允许出现 Worker 域名，不允许出现供应商密钥；Worker 模板见 `worker/weather-proxy/`。
