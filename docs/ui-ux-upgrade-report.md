## 2. 八个参考网站的研究结果

## 3. 现有 UI 问题（按真实页面检查，非推测）

1. **筛选状态不可见**：发现页启用筛选后，页面上除下拉框本身的值外没有任何“当前启用了哪些条件”的汇总，用户从结果页无法一眼确认筛选组合，也没有逐项清除入口（只有无结果时才出现清除按钮）。
2. **卡片信息不足以比较**：卡片只有名称、地区、简介、主题标签；决定行程最关键的“建议玩几天、什么季节去”藏在详情页内，浏览列表时无法横向比较。
3. **详情信息层级扁平**：标题后直接是简介与主题 chip，适游季节（`bestSeasons`）在详情页完全没有展示；各区块之间无页内导航，长页只能靠滚动查找。
4. **对比度缺陷**：陶土强调色 `#C96F2E` 上白字对比度仅 3.62，未达 WCAG AA（4.5），首屏搜索按钮文字受影响。
5. **操作反馈缺失**：收藏切换只改变按钮自身状态，无任何全局反馈；行程保存成功只是一行灰字，不易察觉。
6. **动效与层级未成系统**：卡片无悬停反馈；设计 Token 只有基础色与字号，缺动效时长、圆角档位、阴影档位与拉丁展示字体规范。

## 4. 最终视觉方向

- 首屏：杂志式大图 + 眉题（真实计数）+ 大标题 + 搜索，暗角只服务于文字可读性；区块节奏为“主题横滑 → 精选卡片 → 季节推荐 → 省份入口”。
- 探索：卡片即比较单元（照片 8/5 + 名称 + 地区 + 简介 + 天数/季节 + 主题标签 + 收藏）；筛选状态永远可见、可逐项清除。
- 详情：画廊 → 名称/地区 → 简介 → 事实条（地区/类型/适游季节/建议天数）→ 主题 → 操作 → 页内导航 → 分组信息 → 相关目的地。
- 品牌色与照片同源：深绿 + 暖纸底 + 白卡片 + 墨色正文 + 单一陶土强调色；装饰性渐变一律不用。

## 5. 色彩、字体和布局规范（设计 Token，`assets/css/main.css` `:root`）

色彩（全部组合实测对比度，见第 12 节）：

- 页面背景 `--bg #F7F5EF`、卡片 `--surface #FFFFFF`、次级面 `--surface-2 #FBFAF6`、正文 `--ink #1E2A26`（底色上 13.62）、次级文字 `--muted #5C6B64`（底色上 5.15、白底上 5.61）。
- 品牌主色 `--brand #1F5C4D`（白底上 7.79）、品牌二色 `--brand-2 #166B8A`、品牌字 `--brand-ink #FFFFFF`（品牌底上 7.79）。
- 强调色 `--accent` 由 `#C96F2E` 加深为 **`#B25E1F`**（白字对比度 3.62 → 4.65，达标；仍为暖陶土色）；强调浅底 `--accent-soft #FDF3E3`。
- 边框 `--line #DDD8CB`；警告 `--warn-bg/#FDF3E3 + --warn-ink #7A4A12`（6.79）；错误 `--err-bg #FDECEC + --err-ink #8C2B2B`（7.37）；导航激活底 `#E9F2ED` 上品牌字 6.82。

字体（中文字体实际可用性已核实，见第 2 节 Fontshare 行）：

- 中文正文与标题：`"PingFang SC","Microsoft YaHei","Noto Sans SC",system-ui,sans-serif`（系统字体，零下载）；**不引入任何网络字体，不假设英文字体覆盖中文**。
- 拉丁展示词（首屏眉题、数字）：`--font-latin "Avenir Next","Segoe UI",system-ui,sans-serif`（系统字体，仅用于英文眉题的小字距大写）。
- 字号：基准 16px、小 14px、大 20px、标题 26px、首屏展示 `--fs-display clamp(28px,5.6vw,44px)`；行高正文 1.6、首屏标题 1.2；首屏标题字重 800、字距 -0.01em。
- **未用缩小字体解决任何布局问题**：窄屏仍靠换行、单列、横滑（与既有规范一致）。

布局：

- 内容最大宽 `--maxw 1080px`；卡片网格 `repeat(auto-fill,minmax(250px,1fr))`，窄屏单列；卡片间距 `--gap 16px`；圆角 `--radius-sm 8px / --radius 14px / --radius-lg 20px`；阴影三档 sm/md/lg；断点 720px（≤720 显示底部导航，>720 画廊限高 520px）。
- 动效 Token：`--t-fast 150ms / --t-med 250ms`，仅 transform/opacity；`prefers-reduced-motion` 下全部关闭（既有规则保留）。

组件与动效规范：见第 10 节（筛选芯片、事实条、页内导航、Toast、保存状态条、卡片悬停）。

## 8. 目的地发现页改版结果

- 新增**当前筛选状态条**：启用任一筛选后，结果上方显示“当前筛选：”+ 逐项芯片（关键词原文、省份名、主题 label、季节 label，全部取自真实数据），每项可单独清除（清除后即时重渲染、持久化、URL 同步 push，与既有 URL 同步机制一致）；有结果时另有“清除全部”芯片。

## 11. 图片和动效的处理方式
