## F. 浏览器测试：环境、步骤、结果与限制

本轮目标达成：**建立了不依赖请求拦截的真实 HTTP 浏览器测试**。

- 路径一（新打通）：安装 Playwright 官方 Firefox 构建（firefox-1555，下载于本轮），直连 `python3 -m http.server 8124` 的 `http://127.0.0.1:8124`，站点文件**零拦截**（仅天气 API 请求被 abort 以模拟失败，这一点与真实部署的差异仅在天气失败的触发方式）。脚本 `tests/e2e/smoke-http.mjs`，结果 **16/16 通过，退出码 0**（断言与 Chromium 版相同：首页/筛选/搜索/详情/天气降级/破图降级/收藏/规划/375px 无溢出/无未捕获错误）。夹具为重建的 /tmp 副本（含 1 条 published 测试记录，本轮改用已本地化的真实张家界图片，其中一张全图被故意删除以验破图降级）。
- 路径二（维持）：Chromium 152（/opt/meta-chromium/chrome）在本沙箱仍被 Local Network Access 拦截回环（`ERR_BLOCKED_BY_LOCAL_NETWORK_ACCESS_CHECKS`）；另试访问本机非回环 IP 198.19.0.2，Chromium 返回 `ERR_INVALID_HTTP_RESPONSE`（该地址由沙箱代理接管，非本地服务），此路不通。Chromium 继续用请求拦截版 smoke.mjs，本轮复跑 **16/16 通过**。
- 实际被测层：页面渲染、路由、筛选/搜索、收藏、规划、天气失败降级、破图占位、移动端布局（Firefox 真实 HTTP + Chromium 拦截两套）。
- 仍未测：手机真机（无设备环境，**未执行**）；线上部署环境（无授权）；天气成功路径的浏览器内断言（维持上轮状态）。
