## 1. 呼伦贝尔坐标核验（结论：核验通过，坐标无需修改）

候选记录：呼伦贝尔大草原（莫日格勒河），内蒙古自治区呼伦贝尔市陈巴尔虎旗；当前坐标 49.785,120.1859（WGS-84）；记录语义为“莫日格勒河上游河曲代表观景点”，非景区入口；图片 3 张（草原与蓝天、河畔马群、骆驼与湖泊）。

核验来源与证据（核验日期 2026-10-24）：

- **来源一（地理数据，决定性）**：OpenStreetMap 河道原始几何，Overpass API 实测。河道 way 673039820（name/name:zh 均为“莫尔格勒河”，source 为 digitalGlobe 影像，另有国家地理信息编码 nsdi_code/z... 字段）。当前坐标距该河道最近节点仅 **28 米**（节点 49.784796,120.1861355）；最近节点前后河段节点（49.7851,120.1893 → 49.7851,120.1838）呈弯曲走向，与“河曲代表点”语义一致。OSM 河道整体范围 lat 49.285–49.862、lon 119.233–120.366，本点位位于其东北端上游河段。
- **来源二（河道走向文字资料，交叉佐证）**：中文维基百科“莫日格勒河”条目：该河位于陈巴尔虎旗境内，是海拉尔河右岸支流，发源于陈巴尔虎旗东北鄂温克民族苏木大兴安岭西麓，蜿蜒向西南流经陈巴尔虎旗（核验用原文，非转述推测）。
- **来源三（同名排除与河段区分）**：Wikidata 该河条目（Q29989509）代表坐标为 49.2333,119.3，位于下游一端（近呼和诺尔/海拉尔河汇入段），与本点位相距约 90 公里。分析：该河全长 319 公里，Wikidata 点与本点位是同一河流不同河段的代表点，偏差由此解释，不构成矛盾；本点位不在行政区中心（陈巴尔虎旗政府驻地巴彦库仁镇在下游一带），不在泛化河流位置，而在实测河道线上。

同源性说明（据实记录）：OSM 几何与 Nominatim 地理编码同源于 OSM 数据，因此本轮未把 OSM 几何当作完全独立的第二来源，而是以河道走向文字资料作交叉佐证；决定性证据是几何实测距离（28 米），而非名称检索命中。

结论：坐标 49.785,120.1859 **无需修改**。已将上述证据与偏差分析写入该条目的 verificationNote（措辞由“初步核实、待复核”改为“事实核验通过（2026-10-24）”）；除 verificationNote 外，该条目无任何字段变动；状态仍为 draft。
