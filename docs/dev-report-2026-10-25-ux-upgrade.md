## 3. 回归中发现并修复的两个测试适配问题（断言未放宽）

- `tests/e2e/planner-edit.mjs`：原测试按“日期：名称 — 活动”纯文本解析行内容；每日卡片化后该分隔符不存在，测试崩溃。修复为读取 `.plan-date` / `.plan-name`，交换与日期序列断言本身不变。
- `tests/e2e/sw-offline.mjs`：原测试把版本号 `20261024d` 写死，C 阶段以 d→e 的 sed 模拟升级；产品版本升至 e 后 grep 无命中导致 sed 报错崩溃。修复为从夹具 config.js 读取当前 assetV，升级目标取其后加 `u` 的测试用版本；缓存键与预缓存断言本身不变。
- 两处均为测试跟随产品结构/版本变化而更新，行为断言强度未降低；修复后两专项均全过。
