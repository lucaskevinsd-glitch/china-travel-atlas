## A. 两套设计方向的设计说明

### 方向 A：Editorial Travel Atlas（编辑式旅行图鉴）

- **立意**：把网站当作一本旅行杂志/摄影图鉴来排，而不是当作工具页来摆。标题、图片、留白、栏目节奏是设计主体；搜索、筛选、编辑是配角。
- **首屏**：通栏主视觉（无圆角、顶格到视口边缘），高度 560px（桌面）/ 420px（移动）；双向渐变——顶部暗角解决眉题在浅色天空上对比不足的问题（实测白字/顶部暗角近似色对比度 13.68），底部暗角承载标题；搜索框为白色卡片，以 -32px 负边距压在主视觉底边上，形成“封面 + 检索卡”的杂志结构；图注采用编辑体例（“图：黄山风景区 · 安徽省 ｜ 作者 / 来源（许可）”），每张照片都有署名行。
- **品牌识别装置**：刊头系统——每页顶部“中国旅行图鉴 + CHINA TRAVEL ATLAS · VOL.01 · 2026”刊头 + 通栏细线；区块编号（01 旅行主题 / 02 已发布目的地 / 03 季节推荐 / 04 按省份浏览）；图片说明体例贯穿首页、发现页头图条、详情页。装置在四页保持同一形式，不随意添加装饰。
- **卡片**：编辑式卡片，图片 16/10，首张为“本期主推”跨两列大卡（打破六张同质化），其余标准卡；收藏从全宽按钮降级为图片右上角圆形图标按钮；标签上限 3 个（超出记 +N）；卡片区另含一张“图片加载占位示意”卡（固定比例 + 微光渐变，不再是空白块）。
- **发现页**：窄幅头图条（张掖七彩丹霞真实照片）恢复摄影视觉；筛选工具栏为编辑式（带标签的输入组 + 陶土筛选按钮）；仅剩 1 条（安徽省 → 黄山）时，右侧设“仅剩 1 条时看看”承接区（北京市/重庆市/福建省/甘肃省真实条目），不再孤悬留白。
- **详情页**：主图通栏 16/9 + 桌面端可见左右箭头 + 下方缩略图条（当前张陶土边框高亮）+ “01 / 03”计数，多图在页面内即可发现；标题区只保留“ No.01 · 山岳 · 安徽省 · 黄山市”眉题，**删除与事实条重复的地区行**；事实条改为上下细线分隔的规格表；页内导航吸顶；天气提示条改为浅绿中性底（沿用产品原文“天气暂不可用，请稍后再试。”，不再是粉红报错观感）。
- **规划页**：表单 3 列网格（出发地/日期/天数 / 人数/预算/主题 / 季节 + 生成按钮行），消除 6+1 不对称；日卡片为“陶土日期列 + 封面缩略图 + 名称/地区 + 安静文字编辑操作（上移/下移/后插/删除）”；顶部设草案来源说明行（“本草案保存在当前浏览器中 · 上次保存 00:13 · 草案标题日期为准”）。
- **色彩策略 A（陶土主强调）**：暖纸 #FAF6EE、墨色 #1E2A26、深绿 #1F5C4D 为次、陶土为主强调（刊头标点、区块编号、筛选按钮、生成按钮、画廊激活边框、日期列）。**P1 实测修正**：陶土 #B25E1F 在暖纸上的小字对比度为 **4.32，未达 WCAG AA**；因此 A 方案实行陶土双档——按钮/大色块仍用 #B25E1F（白字其上 4.65，达标），小字（编号、标记）改用加深档 **#9A4E18（暖纸上 5.60，达标）**。实施时必须按此双档执行，不得用 #B25E1F 写小字。

### 方向 B：Modern Field Guide（现代田野指南）

- **立意**：把网站当作一本现代图鉴索引来用：编号、分类、规格行是设计主体；照片是索引的配图，但每张都有编号与归属。
- **首屏**：不做巨型主视觉，改为深绿顶栏（圆形“图鉴 FIELD”徽标 + 站名 + 真实规模行）+ 紧凑标题区 + 搜索 + 快捷分类 chips + 三张封面照片条（No.01 黄山 / No.02 故宫 / No.03 洪崖洞，带编号角标与图注）。摄影存在感来自照片条与卡片，而非一张大图压全屏。
- **品牌识别装置**：编号系统 + 坐标徽标——顶栏徽标每页一致；卡片带 No.01–No.06 角标；详情页顶栏带 No.01；画廊计数为 01 / 03；规划页为 DAY 01/02/03；发现页同主题索引用真实编号（恩施大峡谷 No.12、张家界 No.13、长白山天池 No.14，均取自正式索引顺序）。
- **卡片**：图鉴条目卡，图片 4/3，左上角深绿编号角标，右上角圆形收藏图标按钮；正文为规格行（地区 / 建议天数 / 适游季节，分行标注）；主题标签按家族着 muted 淡色（山岳/自然风光=浅绿、历史人文=浅陶、海岛海岸=浅蓝、摄影=浅灰），同一家族同色，不同家族可区分；另含一张 4/3 加载占位示意卡。
- **发现页**：桌面端左侧筛选栏（sticky，筛选组 + 顶部已选芯片 + 深绿筛选按钮），右侧结果区；移动端筛选栏转为顶部通栏。仅剩 1 条时，下方设“同主题索引 · 山岳”紧凑行（真实条目 + 真实编号），承接空荡感。
- **详情页**：主图 16/9 圆角 + 桌面端可见左右箭头 + 下方胶片条（当前张深绿边框）+ 01 / 03；左侧 sticky 页内导航（桌面），移动端转为顶部 pills；右侧规格表（含数据来源、最近核验 2026-10-22 两行真实信息）；天气不单独成条，改为规格表内一行（“天气：暂不可用，请稍后再试。”，深绿字），彻底消除粉红报错观感；标题区地区信息只在规格表出现一次，无重复。
- **规划页**：表单同为 3 列网格；日卡片为“深绿 DAY 编号列 + 封面缩略图 + 名称/地区 + 安静文字编辑操作”；草案来源说明行与 A 方案同文案、不同样式。
- **色彩策略 B（深绿主强调，陶土仅作主操作）**：纸底 #F7F5EF、深绿 #1F5C4D 为主强调（顶栏、编号、激活态、筛选按钮、导航激活），陶土 #B25E1F 仅用于主操作按钮（搜索、生成行程草案，白字其上 4.65，达标）；浅绿 #EAF1EC 为次级面。全部文字组合实测达标（白字/深绿 7.79、深绿字/浅绿 6.78、蓝字/浅蓝 5.23、陶土深字/浅陶 6.79）。

### 两套方案的实质差异（不只是换色）

| 维度 | 方向 A Editorial | 方向 B Field Guide |
|---|---|---|
| 首屏结构 | 通栏大图 + 压边搜索卡 | 深绿顶栏 + 紧凑标题 + 三图照片条 |
| 品牌装置 | 刊头 + 期号 + 区块编号 + 图片说明体例 | 徽标 + 全站编号系统 + 规格表 |
| 卡片形态 | 编辑卡（16/10、首张跨列主推） | 索引条目卡（4/3、编号角标、规格行、主题家族色） |
| 发现页结构 | 顶图条 + 工具栏 + 右侧承接区 | 左侧筛选栏（sticky）+ 同主题紧凑索引 |
| 详情页导航 | 顶部吸顶 pills | 左侧 sticky 栏（桌面）/ 顶部 pills（移动） |
| 强调色角色 | 陶土主导（双档修正后） | 深绿主导，陶土仅主操作 |
| 圆角/阴影性格 | 小圆角、杂志式硬朗细线 | 12px 圆角、柔和卡片阴影 |

## C. 设计规范（两套方案的共性 + 差异）

**共性（实施时两方向都必须遵守）**：

- 字体：中文系统栈 `"PingFang SC","Microsoft YaHei","Noto Sans SC",system-ui,sans-serif`，零网络字体；拉丁展示词仅用于眉题、编号、坐标类短词（小字距大写），不得用于中文。
- 字号层级：正文 16px / 行高 1.6–1.7；辅助 13–14px；卡片标题 19–20px；页面标题 26–30px；首屏展示 A 为 clamp(34px,6vw,64px)、B 为 clamp(28px,4.5vw,40px)。
- 留白：内容列 A 为 1120px、B 为 1120px；区块间距 28–44px；卡片内边距 12–16px；卡片间距 16–20px。
- 边框：细线 #DDD8CB；卡片边框 1px；A 用 2px 墨色通栏线作刊头规则，B 用深绿顶栏作分区。
- 阴影：卡片默认 sm（0 1px 3px rgba(30,42,38,.08)）；悬停/重要卡片 md（0 12px 32px rgba(30,42,38,.18)）；搜索卡 md。
- 圆角：A 卡片 0–6px（硬朗）、主视觉 0；B 卡片 12px、输入框 12px、主视觉 12px。
- 图片比例：卡片 A 为 16/10、B 为 4/3；详情主图两方向均为 16/9；规划日卡片缩略图 16/10；发现页头图条（A）为通栏裁切 220px 高。
- 按钮：主操作最小高度 48px；卡片内收藏为 44px 圆形图标按钮（触摸目标达标）；编辑操作为安静文字按钮（不再是每卡四个带框按钮）。
- 表单：标签在上、控件在下；控件最小高度 44px；规划表单 3 列网格，窄屏单列、按钮全宽。
- 画廊：主图 + 缩略图/胶片条（当前张彩色边框高亮）+ 桌面端可见左右箭头（48px）+ 计数（01 / 03）；灯箱箭头加大内收（实施时沿用此原则）；懒加载图片必须有固定比例占位（微光渐变 + 图片符号），不得出现空白块。
- 反馈状态：筛选状态条（已选芯片 + 逐项清除 + 清除全部）；收藏切换（图标填充 + Toast，沿用产品现有 Toast）；保存提示条（沿用产品现有样式）；空态承接区（仅剩 1 条 / 无结果时给出去向，不得留白）；加载占位（见上）。
- 无障碍：全部文字组合对比度 ≥4.5（实测见本报告 A/B 两节，A 方案小字陶土须用 #9A4E18 档）；键盘可见焦点（3px 描边，沿用产品现有规则）；`prefers-reduced-motion` 下关闭一切过渡与揭示动效；图片 alt 沿用正式记录 alt；收藏按钮带 aria-label。
- 动画：只作必要交互说明——本样稿为静态，画廊切换、筛选联动、收藏状态变化均不实际联动（样稿顶部已标注）；实施时动效只允许操作反馈、加载占位、区块揭示三类，预算 150–250ms、仅 transform/opacity。

**差异速查**：强调色（A 陶土双档 / B 深绿 + 陶土主操作）；圆角性格（A 硬朗 / B 柔和）；卡片信息组织（A 叙述行 / B 规格行）；发现页结构（A 顶栏 + 右侧承接 / B 左侧栏 + 紧凑索引）；详情导航（A 吸顶 pills / B 左侧栏）。

## D. 方案对比表

| 维度 | 方向 A Editorial Travel Atlas | 方向 B Modern Field Guide |
|---|---|---|
| 品牌识别度 | 高。刊头 + 期号 + 编号 + 图片说明体例，四页一眼同属一本图鉴；但“杂志感”依赖摄影质量，弱图页面会打折 | 高。徽标 + 编号系统在任何页面都可识别，不依赖大图；但编号感偏工具，杂志气质弱于 A |
| 首屏视觉冲击力 | 最强。通栏大图 + 64px 标题 + 压边搜索卡，气势问题直接解决 | 中等。标题区紧凑、照片条分散注意力；冲击力来自秩序而非气势 |
| 摄影表现力 | 最强。主视觉、头图条、详情通栏、图注体例，照片始终是主角 | 较强。照片条 + 卡片 + 画廊都有编号归属，但单张照片的篇幅小于 A |
| 信息可读性 | 良好。叙述行易读，但卡片信息需读整句；规格对比不如 B 一眼 | 最好。规格行（地区/天数/季节）逐行对齐，横向比较最快 |
| 发现页布局适应性 | 良好。顶图条 + 工具栏直观；仅剩 1 条时右侧承接区有效；但筛选控件仍在顶部，长筛选条件会挤压结果区 | 最好。左侧栏可容纳更多筛选组而不挤压结果；移动端需把栏收进顶部，实施稍复杂 |
| 详情页多图发现性 | 好。缩略图条 + 箭头 + 计数，三重提示 | 好。同 A，但胶片条 + 左侧栏使页面更像“图鉴条目” |
| 规划页实用性 | 良好。表单平衡、日卡片图文结合、来源说明齐全 | 良好。同 A；DAY 编号 + 深绿日期列使多日行程的顺序感更强 |
| 移动端适配 | 良好。通栏主视觉在窄屏表现好；但 390 下眉题换行略显局促（截图实测，实施时须控制为均衡两行或缩短文案） | 良好。紧凑标题区在窄屏更稳；左侧栏转顶部是主要实施点 |
| 实现复杂度 | 中。主视觉通栏化、搜索卡负边距、吸顶导航、刊头系统，均为 CSS/结构改动，无新依赖 | 中低。顶栏、编号角标、规格行、左侧栏均为现有组件的变体；左侧栏 sticky 与移动端收起需注意 |
| 与现有项目兼容性 | 中。需改动首页结构、详情页结构、卡片模板；Token 需新增陶土深档；其余（路由、数据、SW）不动 | 高。卡片、筛选、详情、规划的改动都落在现有组件内；深绿主强调与现有品牌色一致，Token 变动最小 |

## E. 实施清单

### 可直接修复的明确缺陷（不等方向确定即可实施，与两方向无关）

1. 详情画廊增加缩略图/胶片条 + 桌面端可见箭头 + 计数（两方向方案一致）。
2. 图片加载占位（固定比例 + 微光 + 图片符号），替换米色空白块。
3. 卡片收藏按钮从全宽描边按钮降级为 44px 圆形图标按钮。
4. 详情页删除标题下与事实条重复的地区行（只保留事实条/规格表）。
5. 天气提示条改系统配色（A 的浅绿底或 B 的规格表内行），废除粉红报错观感；文案沿用产品原文。
6. 省份入口 31 省横滑改为换行 + 展开/收起（审计已定，样稿中 A 方案已示意“＋ 展开全部 24 省”）。
7. 规划表单 3 列网格化，消除 6+1 不对称；日卡片配封面缩略图（`coverThumb` 已有数据，零新增请求）。
8. 草案来源说明行（“本草案保存在当前浏览器中 · 上次保存时间 · 草案标题日期为准”）。
9. 删除未使用的 `--accent-soft` 或给它真实用途；A 方案陶土小字必须用 #9A4E18 档（对比度实测结论）。
10. 灯箱箭头加大内收、不贴边；底部来源文字缩短为“图：名称 ｜ 作者（许可）”体例。

### 必须等视觉方向确定后才能实施的改动

1. 首页首屏结构（A 通栏 + 压边搜索卡 vs B 顶栏 + 照片条）。
2. 品牌识别装置全套（A 刊头/期号/编号/图注体例 vs B 徽标/编号系统/规格表）。
3. 强调色体系（A 陶土主导双档 vs B 深绿主导 + 陶土主操作）。

7. 圆角/阴影性格全套（A 硬朗小圆角 vs B 12px 柔和卡片）。

### 暂不建议实施的设计想法

1. 3D 图标点缀（3dicons）：许可细则未复核（审计结论），且与两方向的摄影主调都不协调；如未来空态需要，先核对许可再以本地文件引入。
2. 滚动揭示/视差动效：上一轮声称未落地；本轮样稿未用它证明视觉价值，且增加 IntersectionObserver 与减动效分支成本；如需，只限首页区块标题轻微上浮，不得用于全站。
3. 地图、预订、价格、日历支付、新页面：审计外需求，本轮明确不做。
4. 远程字体 / CJK 网络字体：中文标题仍无可用网络字体，系统栈决策不变。
5. WebGL / Spline / Lottie 运行时 / 视频背景：与“照片优先、零新增依赖”冲突，继续拒绝。
6. B 方案主题家族色扩展到全站导航：样稿中仅用于卡片标签；扩展到导航会增加色彩噪音，暂不建议。
